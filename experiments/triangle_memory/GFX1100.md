# gfx1100 N1000 triangle layout experiment

This experiment continues the qualified OpenFold3 softmax and rollout/template
reuse composition on Precision. It is a frozen experimental route, with native
FP32 arithmetic, strict determinism and allocation filling preserved.

## Motivation and scope

A separately accepted diagnostic run found approximately 151.45 seconds inside
four pairformer passes and 30.27 seconds inside the diffusion rollout. These are
inclusive GPU-event intervals with diagnostic overhead; the denoiser interval
is nested within the rollout. A sampled steady pairformer block attributes
12.5% of its kernel time to the largest direct-copy kernel, 8.1% to the largest
fill kernel and 7.8% to LayerNorm. They do not establish hardware saturation.
See `provenance/precision_openfold3_profile_gfx1100_20261019.json`.

The candidate uses the existing `copy.cpp` uint32 tiled transpose, newly built
for gfx1100 through the Rust HIP build service. `gfx1100_copy.py` substitutes
selected projection writes, explicit native BMM operand packing and layout
materialization before native normalization. Mathematical operations, chunking,
recycle count and diffusion schedule remain unchanged. The original gfx90a
runtime is unchanged; the new wrapper admits only N1000 chunks256/tail232.

The source-pinned hook requires inference mode, strict deterministic FP32,
allocation filling, the measured Torch/HIP versions and gfx1100. Unsupported
calls use native execution. A library digest mismatch and zero candidate HIP
coverage fail the trial. Hooks restore the original method on exit, including
exceptions. The kernel treats data as bits and preserves NaNs and signed zero.

## Evidence and execution

Workload: OpenBind-0, N1000, R3/four passes, D200/S1, seed101, query-only MSA,
no templates, HIP0 / PCI `0000:53:00.0`, W7900. Original pinned checkpoint and
native reference remain unchanged. Each candidate must match all 11 exported
arrays and complete CIF bytes against the maintained native prediction.

The 12-case operator screen covers row/column projection writes, BMM packing,
normalization layouts, leading/interior/tail chunks, destination canaries,
nondefault streams and native fallbacks. Projection/BMM-copy timings improve
4.10–6.81x; normalization-copy changes are small. These are copy timings, not
full attention or E2E speedups. Destinations are already allocated in this
microbenchmark; complete model timing retains allocation and deterministic filling.

The first full-model candidate passed all gates with 430 eligible triangle
calls, 3,440 HIP copies, 1,720 native copy fallbacks and the unchanged 1,696 HIP
softmax submissions. Its single 232.323-second complete invocation and
201.820-second forward are diagnostic observations. Three AB/BA/AB pairs are
required before a repeated E2E claim.
